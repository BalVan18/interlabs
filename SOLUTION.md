## Что сделано и что не успел

**Сделано:**
- Экран «Матчи тура»: загрузка с `MATCHES_URL`, состояния loading / error / empty / data.
- Карточка матча: хозяева и гости, счёт (если есть), дата и время в часовом поясе устройства, статус по-русски в цветном бейдже.
- Фильтр «Все / Предстоящие / Завершённые», кнопка «Обновить» + pull-to-refresh.
- `UpdatedAgo` под заголовком, тикает каждую секунду и сбрасывается при обновлении данных.
- Избранное: звёздочка на каждой карточке, независимое состояние, pop-анимация при тапе.
- Легкие анимации: карточки плавно появляются (stagger), у `live` пульсирующая красная точка.
- Утилиты `extractMatches`, `teamName`, `scoreParts` — защита от реальной схемы данных (команды приходят объектами).
- Починены баги в `useFavorites` и `UpdatedAgo`.

**Не успел / сознательно не делал:**
- Персистентность избранного (AsyncStorage).
- Офлайн-кэш матчей.
- Юнит-тесты — ограничился ручной проверкой на web + iOS/Android через Expo Go.
- Hover на web убран намеренно: `react-native` не типизирует `hovered` в `PressableStateCallbackType`, а press-feedback работает на всех платформах и не требует обёрток или `@ts-ignore`.

## Решения

**Куда отнёс матчи с нестандартными статусами:**

| Статус      | Все | Предстоящие | Завершённые |
|-------------|:---:|:-----------:|:-----------:|
| `scheduled` |  ✓  |      ✓      |             |
| `live`      |  ✓  |      ✓      |             |
| `postponed` |  ✓  |      ✓      |             |
| `finished`  |  ✓  |             |      ✓      |
| неизвестный |  ✓  |             |             |

- **`live` в «Предстоящих»** — матч идёт, но ещё не финал, искать его логично среди незавершённых.
- **`postponed` в «Предстоящих»** — матч не сыгран, просто перенесён.
- **Неизвестный статус** — только во «Все», чтобы не терять данные. В карточке показывается как есть.

**Неочевидные случаи в данных, которые нашёл:**

1. `home` и `away` — не строки, а объекты `{id, name, city}`. При прямом рендере React падал с `Objects are not valid as a React child`. Сделал хелпер `teamName`, который аккуратно достаёт `name` (или `title`, если схема поменяется).
2. Матч `postponed` со `startsAt: null`. В карточке вместо даты — «Дата не назначена», статус — «Отложен». Матч не теряется.
3. `score` может быть `null` или объект со вложенной структурой. Сделал `scoreParts`, который ищет числа в нескольких возможных полях (`home`, `homeScore`, `{score: n}`) и возвращает `null`, если счёт неизвестен — карточка рендерится без блока счёта.
4. Корень JSON — не всегда массив: возможны `{matches:[…]}`, `{data:[…]}`, словарь по id. `extractMatches` приводит любой вариант к массиву и бросает понятную ошибку на неизвестном формате. Это страховка от `matches.filter is not a function`, если сервер изменит формат.

## Баги из части 2

1. **Звёздочки горят у всех, нажатие непредсказуемо.**
    - **Почему так происходило:** в `isFavorite` было `Boolean(favorites.indexOf(id))`. Для первого избранного `indexOf === 0`, `Boolean(0) === false` → звезда не загоралась. Для отсутствующего `indexOf === -1`, `Boolean(-1) === true` → у всех остальных «горело». Плюс `toggle` мутировал массив и вызывал `setFavorites(favorites)` с той же ссылкой — React не видел изменения и не перерисовывал.
    - **Что исправил:** `isFavorite` — через `favorites.includes(id)`. `toggle` — через функциональное обновление `setFavorites(prev => prev.includes(id) ? prev.filter(x => x !== id) : [...prev, id])`, всегда новый массив.

2. **«Обновлено N сек назад» замирает.**
    - **Почему так происходило:** `setInterval` замыкал `seconds === 0` на первом рендере, поэтому `seconds + 1` всегда давал `1` от нуля — счётчик не рос. Не было `clearInterval` — утечка при размонтировании. При обновлении данных `lastUpdated` менялся, но `useEffect` с пустыми зависимостями не перезапускался и не сбрасывал счётчик.
    - **Что исправил:** `setSeconds(prev => prev + 1)` в интервале; `return () => clearInterval(timer)` в `useEffect`; `since` добавлен в зависимости, в начале эффекта — `setSeconds(0)`.

## Как я использовал ИИ

Инструменты: **ChatGPT / Claude** как помощник по коду и диагностике.

**1. Диагностика `matches.filter is not a function`.**
ИИ сначала предложил проверку `Array.isArray(json) ? json : []`, но это скрывало бы реальную причину — JSON был валидный, просто не массив в корне. Заметил по логу: `res.ok === true`, `res.json()` не падал. Переписал под `extractMatches`, которая явно логирует / бросает ошибку на неизвестном формате, а не молча отдаёт пустой список.

**2. Фикс `Boolean(favorites.indexOf(id))`.**
ИИ в первом ответе написал `favorites.indexOf(id) !== -1` — это работало, но не решало вторую половину бага (мутацию массива в `toggle`). Заметил по поведению: после первого клика звезда гасла, а следующая «загоралась» у всех подряд — значит проблема была не только в `isFavorite`. Добавил функциональное обновление состояния.

**3. Типизация `hovered` в `Pressable`.**
ИИ предложил `@ts-ignore` — плохое решение, потому что ошибка вернулась бы на следующем рефакторинге. В итоге отказался от hover в пользу `pressed`-feedback: работает на web и native, не требует своей обёртки и не ломает типы.

**Проверка результата:** после каждого фикса прогонял `npx tsc --noEmit` (чисто) и `npm run web` — экран грузится, состояния переключаются, звёзды независимы, счётчик тикает. Дополнительно проверил на iOS/Android через Expo Go.

## Что улучшил бы, будь ещё 2 часа

1. **Персистентность избранного** через AsyncStorage — чтобы выбор сохранялся между запусками.
2. **Офлайн-кэш матчей:** при старте сразу показывать последний сохранённый список, параллельно тянуть свежий; бейдж «офлайн» при отсутствии сети.
3. **Юнит-тесты** на `matchesFilter`, `extractMatches`, `useFavorites` (граничные случаи с `indexOf`) и `UpdatedAgo` (тиканье + сброс при смене `since`) — Jest + RNTL.
4. **Поиск и сортировка:** поиск по названию клуба, сортировка по времени начала (по возрастанию для «Предстоящих», по убыванию для «Завершённых»).
5. **Улучшенные ошибки:** различать «сеть недоступна» и «сервер ответил ошибкой», плюс баннер с «Повторить» и на экране с уже загруженными данными.
6. **Тёмная тема** — палитра уже вынесена в `PALETTE`, останется подменить через `useColorScheme`.
7. **Авторефреш live-матчей** каждые 30–60 секунд, пока вкладка активна и в данных есть `live`.
